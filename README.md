# Invitación de XV años de Joseline

Proyecto React + Vite listo para publicar en Vercel.

## 1. Agregar fotografías y música

Copia estos archivos dentro de `public/` usando exactamente estos nombres:

- `foto-principal.jpg`
- `foto-1.jpg`
- `foto-2.jpg`
- `foto-3.jpg`
- `foto-4.jpg`
- `musica-xv.mp3`

Puedes sustituirlos después sin cambiar el código.

## 2. Probar localmente

```bash
npm install
npm run dev
```

## 3. Compilar

```bash
npm run build
```

## 4. Publicar en Vercel

1. Sube esta carpeta a un repositorio de GitHub.
2. Entra a Vercel y selecciona **Add New > Project**.
3. Importa el repositorio.
4. Vercel detectará Vite automáticamente.
5. Pulsa **Deploy**.
